## 🎮 Как это работает?

Змейка "пожирает" ваши GitHub контрибуции, создавая динамичную анимацию из вашей активности. 

### 📊 Что означают цвета:
- 🟩 **Зеленая змейка** - ползает по сетке контрибуций
- 🟨 **Желтые квадраты** - ваши коммиты, которые змейка уже "съела"
- 🟦 **Синие квадраты** - ваши контрибуции разной интенсивности:
  - ░░░░░░░░▀ - 1-2 коммита
  - ░░░░░░░▀▀ - 3-4 коммита  
  - ░░░░░░▀▀▀ - 5-6 коммитов
  - ░░░░░▀▀▀▀ - 7+ коммитов

### 🔄 Частота обновления
Анимация автоматически обновляется каждые 12 часов или при каждом push в репозиторий.

---

## 🛠️ Технологии

- **[Snk](https://github.com/Platane/snk)** - Генератор змейки для GitHub
- **GitHub Actions** - Автоматизация процесса
- **SVG анимация** - Легковесная векторная графика
